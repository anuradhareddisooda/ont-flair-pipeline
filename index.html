Quick start
  1. Samples — Add each sample, name it, and paste the path(s) to its FASTQ.gz file(s). For multi-lane data, click "Add lane/file" and add the second (or third…) file — they'll be cat'd automatically.
  2. Reference — Set the genome FASTA, GTF annotation, output directory, and conda env name.
  3. Parameters — Toggle FLAIR flags as needed. Switch to transcriptome mode if you're starting from sorted BAMs.
  4. Script preview — Copy or download the shell script, then run it on your HPC.
Pipeline steps
01 flair align      Map ONT reads to the genome (minimap2 under the hood)
02 flair correct    Fix splice junctions using GTF annotation
03 flair collapse   Collapse corrected reads into isoform models
04 flair combine    Merge isoforms across all samples into a unified set
05 flair quantify   Quantify isoform expression per sample
06 predictProductivity   Predict ORFs, productive vs NMD isoforms
07 plot_isoform_usage   Plot isoform proportions for your gene of interest
